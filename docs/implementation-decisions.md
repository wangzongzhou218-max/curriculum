## 前端设计（frontend-design）

课程是按学期组织、反复查询和修改的教学资料。界面以课程编号、完整授课安排、状态和操作为信息主线，操作后的结果常驻在上下文内。

色彩：纸白 #FFFFFF、工作区灰 #F3F5F8、文字墨蓝 #20334D、操作蓝 #245BC2、分隔灰 #DFE5ED、错误红 #B33439。12 色课表保留 design.md 原色值。

字体：正文与控件使用 Microsoft YaHei UI / Microsoft YaHei；标题沿用同一字体、加强字重，数字使用等宽数字特性。标题 26px、分区 18px、正文 14px、辅助 12px。内容左对齐，按钮和状态保持稳定列宽。

布局选择：顶部横向导航会让三角色页面层级与学期栏竞争空间，采用固定 208px 侧栏；主体使用一张连续表格，保留清楚的行操作。表格、表单和对话框使用不同密度，不把所有信息装入重复卡片。

```text
┌ 选课系统 ─┬ 当前页面                            姓名 / 角色 / 退出 ┐
│ 课程管理  │ 标题 + 说明                             主操作按钮   │
│ 学生总览  │ 学期选择  起止日期  状态                              │
│ 周课表    │ 筛选 / 查询                                          │
│           │ 编号 名称 完整授课安排 状态 人数 操作                 │
│           │ 连续表格 / 完整五日课表                               │
└───────────┴ 分页 / 结果反馈 ──────────────────────────────────────┘
```

审视设计后去掉无业务意义的统计卡、装饰性编号和大幅欢迎区。唯一明显的视觉特征是课程安排的可读色标及五日时间网格；其余空间服务于辨认信息和安全确认。
